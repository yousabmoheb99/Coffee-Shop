# ☕ Coffee Shop Website (Caffeine Cove)

A modern, clean, and fully responsive website landing page for **Caffeine Cove** Coffee Shop. Built using semantic HTML5 and custom CSS3 with responsive layouts for all device screens.

---

## 🌐 Live Demo
🔗 [Explore Caffeine Cove Online](https://yousabmoheb99.github.io/Coffee-Shop/Coffe_Web/)

---

## ✨ Key Features
- **Header & Navigation:** Fixed navigation bar with smooth section links.
- **Hero Section:** Eye-catching landing showcase with a direct Call to Action.
- **About Section:** Story and core values highlighting sustainability and quality.
- **Interactive Menu:** Grid layout displaying popular coffee drinks and pricing.
- **Testimonials:** Customer reviews formatted in clean card components.
- **Reservation & Contact Form:** Table booking form integrated with an embedded Google Map.
- **Responsive Layout:** Optimized for desktops, tablets, and mobile phones via CSS Media Queries.

---

## 🛠️ Tech Stack & Tools
- **HTML5** - Semantic markup structure
- **CSS3** - Custom styling, Flexbox, Grid, and Media Queries
- **Google Fonts** - *Oswald* & *Open Sans*
- **Font Awesome** - Vector icons
